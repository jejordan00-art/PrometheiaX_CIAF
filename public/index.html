Arquitectura Técnica y Regla N

Requisitos de la rúbrica oficial CIAF

1. Separación Estricta de Responsabilidades

  • routes/turnos.routes.js: Define endpoints limpios y los asocia a sus controladores.
  • controllers/turnos.controller.js: Valida entradas JSON, asigna códigos HTTP (200, 201, 400, 404) y responde al cliente.
  • services/turnos.service.js: Contiene la fórmula matemática, la lógica de negocio y lee/escribe en data/turnos.json.

2. Regla de Negocio del Equipo (N)

porcentajeRecargo = N × 2%
totalPagar = precioBase + (precioBase × porcentajeRecargo / 100)

Si prioritario = false o no se especifica, totalPagar = precioBase sin recargo.

3. Parámetro N Activo en el Servidor

N = 7
Configuración por variable de entorno
Modificable en .env con EQUIPO_N=<valor> sin alterar el código fuente.

4. Almacenamiento Local

Los datos se guardan en data/turnos.json en tiempo real, garantizando persistencia local según lo solicitado en el taller.

Solicitudes de Asesoría Registradas

Registros persistidos en data/turnos.json. Esta sección consume directamente GET /api/turnos y GET /api/turnos/:id.

Prueba de Códigos HTTP: Usa un ID existente (ej: 1) para ver HTTP 200 OK. Usa un ID que no exista (ej: 9999) para verificar HTTP 404 Not Found.
